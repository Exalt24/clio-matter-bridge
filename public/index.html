clio-matter-bridge

This deployment is a webhook receiver for Clio Manage, not a browsable site. It accepts signed POST requests from Clio at /api/clio-webhook and verifies each one with an HMAC signature before doing anything with it.

There is nothing to see here in a browser. Source, tests, and the measured API notes are on GitHub: github.com/Exalt24/clio-matter-bridge.
